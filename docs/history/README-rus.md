# История API

> На английском: [`README.md`](README.md)

Здесь сохранены артефакты, удалённые из рабочего дерева ветки `public`,
но нужные для понимания того, как менялась методика.

## `api_v0.1_legacy.py`

Автосохранение Jupyter (`.ipynb_checkpoints/eyetracking_funs-checkpoint.py`)
с предыдущей версией API. Ценно тем, что документирует исходные формулы методики
до реорганизации кода в четыре модуля (коммит `e7ace89`) и до оптимизации
(коммит `c08eda7`).

Соответствие удалённых функций текущим:

| Функция прежней версии | Чем заменена | Замечание |
|---|---|---|
| `find_full_angel(eye_data, x_key, y_key, k, x0, y0)` | часть `_mark_eye_data_with_full_angle_planar_impl` | возвращала `dp` (радиальное смещение) и `alpha` (полярный угол) как **две разные** величины |
| `make_full_coord(eye_data, key_x, key_y, ...)` | часть того же impl | считала `pos = atan2(dp, 12)` — угловой эксцентриситет, и отдельно `alpha` — направление |
| `find_saccade(full_coord, max_peak, win)` | `_build_saccades` | детекция шла по производной **эксцентриситета** |
| `find_fixation(full_coord, saccade_list, ...)` | `_build_fixations_between_saccades` | простой порог по скорости, без проверки однородности |
| `find_gaze_fixation(full_coord, max_vel, max_delta_time, max_peak, fr)` | `mark_eye_data_*` | отдельная ветка для «взора»; в текущей версии удалена |
| `eye_params(fr, n)` | `models.min_saccade_minima_by_sampling` | возвращала **два** порога: `vs_max` (саккада) и `vf_max` (фиксация) |
| `combine_times(row, col_pitch, col_yaw)` | удалена | сохранилась только в checkpoint-версии `gaze_mark.py` |

Важное наблюдение по `eye_params`: при любых реальных сочетаниях частоты и числа
отсчётов (`n / fr <= 0.21 с`) она уходила в вырожденную ветку и возвращала
константы `vs_max = 15`, `vf_max = 5` независимо от частоты. Именно эти значения
закреплены сейчас как значения по умолчанию `max_peak=15` и
`max_vel_on_fixation=5` в функциях разметки, то есть частотной зависимости
в них нет.

## `about_functions_notebook.md`

Текст из удалённого ноутбука `about_functions.ipynb`: описание входных данных,
допущение о движении зрачка по сфере постоянного радиуса, роль калибровки
и нейтрального положения.
